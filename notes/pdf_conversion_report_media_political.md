## 2) منهجية الاستخراج — الموسوعة السياسية

بنية المدخل: `• المصطلح العربي (مكرر بسبب طبقة نص مزدوجة) • English Term ثم التعريف`.

1. تطبيع NFKC + إزالة علامات الاتجاه (bidi) والتطويل (ـ).
2. إسقاط رؤوس الصفحات (العنوان + رقم الصفحة) **فقط** في صدر الصفحة — لأن أرقام
   المحتوى (١٩٤٨ إلخ) تشاركها نفس الهيئة.
3. طي الأسطر المتطابقة المتجاورة (الطبقة المزدوجة).
4. التقطيع عند كل `•` (وحتى منتصف السطر لنمط `( •OPEC)`).
5. تجميع: [مقطع عربي قصير] ← [مقطع إنجليزي + تعريف] مع ابتلاع مقاطع التعريف الزائدة.
6. **عكس سلاسل الأرقام العربية** المخزنة بالترتيب البصري: ٨٤٩١ ← ١٩٤٨.
   تحقّق تاريخي: كفر قاسم ١٩٥٦ ✓، تل الزعتر ١٩٧٦ ✓، صبرا وشاتيلا ١٩٨٢ ✓،
   إسكيبولاس الثانية ١٩٨٧ ✓ (116 تاريخاً مصححاً).
7. إدخالات الإحالة (`أمريكا America / أنظر ...`) فُصلت إلى (ar, en, note) — 78 إحالة.
8. إصلاح انشطارات الكلمات (`ا لأرض`→`الأرض`، `ع ك سية`، `التعا ون`→`التعاون`) وطي
   تكرار الطبقات على مستوى العبارة (26 مصطلحاً).

**النتيجة:** 1035 مدخلاً (1030 زوجاً ثنائياً + إحالات)، 1007 تعريفات (97.3%)،
268 تعريفاً يحوي إنجليزية مضمَّنة → منها 434 زوج عبارات/جمل ثنائية
(412 التقاطاً محكماً «عبارة عربية ↔ English» + 22 سياقية).

## 3) منهجية الاستخراج — معجم الإعلام

بنية الكتاب: **مسرد عربي** (ص9–32: عربي/إنجليزي) + **متن إنجليزي** (ص33–121:
المصطلحان + تعريف عربي). طبقة النص للتعريفات مشوّهة بشدة (استُبعدت)، أما
طبقة المصطلحات فأُصلحت بالتالي:

### خريطة الفساد المكتشفة (موثقة بالخوارزمية R17)
| الظاهرة | المثال | الإصلاح |
|---|---|---|
| كودپوينتات نادرة | وسائؿ، صُحؼ، الحقائؽ، مُشارؾ | ؿ→ل، ؼ→ف، ؽ→ق، ؾ→ك، ػ→غ |
| انقلاب ربطات لام-ألف | االتجاه، اإلعالف، األنباء | اال→الا، اإل→الإ، األ→ال+أ |
| تطويل طرفي = م ساقطة | العاـ، فيمـ، نظاـ | ّـ←م في آخر السطر |
| نونه أخيرة→ف | عنواف، بياف، إعالف | خريطة كلمات (44 شاهداً من تصويت القسمين) |
| لام→ميم | تحميل(=تحليل)، حممة(=حملة)، المعمومات(=المعلومات) | خريطة كلمات موجَّهة |
| هاء→ياء/ألف مقصورة | تمييد(=تمهيد)، جماىيرية، شاىد | خريطة كلمات |
| انشطار كلمات سطرياً | كمم+ة مفتاح، س+ؤاؿ، لقطة ر+ئيسية | دمج متعدد الأسطر بلا مسافة عند الحدود المكسورة |
| ى مصرية | سياسى، الرأى | توحيد إلى ي مع قائمة بيضاء (على/حتى/أخرى/صدى/مدى...) |

كل مصطلح يظهر في القسمين (570×2 استخراج مستقل) بدرجات فساد مختلفة؛ اختيار
الأصلح بالتسجيل، مع **192 تجاوزاً مقنناً** لحالات استعصت (مثل
`peak viewing hours → ساعات ذروة المشاهدة (في التليفزيون)` المستعادة من

(1405 صفاً) تبيّن أنه **طبعة/مصدر مختلف** (ترجماته تختلف جوهرياً: bad news→خبر سيئ
