# قواعد وملاحظات عملية في الترجمة (عربي ↔ إنجليزي)
# Arabic–English Translation Notes: Rules & Decision Logic

المصدر: «ملاحظات الترجمة العربية–الإنجليزية» — إعداد حياة دكار (طالبة ترجمة، الإصدار الأول 2026).
ملخص منهجي للقواعد العملية الواردة في الملف، مهيأ للاستخدام في تطبيقات الترجمة ومحركات القواعد.

---

## 1. أسس الترجمة من العربية إلى الإنجليزية (Foundations)

1. **ترتيب الجملة الإنجليزية:** `Subject + Verb + Complement (S + V + C)` — يُعاد بناء الجملة وفق النظام الإنجليزي، لا ترجمة كلمة بكلمة.
   - مثال: «كتب الطالبُ الدرسَ.» → `The student wrote the lesson.`
2. **قراءة النص كاملاً قبل الترجمة** لتحديد: المعنى الصحيح للكلمات، وتجنب الحرفية، والمحافظة على الترابط، وتوحيد المصطلحات. ويُفضَّل ترجمة العنوان بعد الانتهاء من النص.
3. **تجنب الترجمة الحرفية:** ابحث عن المعنى المقصود والتعبير الطبيعي.
   - «مَدَّ يد العون» → `Help / Give a helping hand / Lend a helping hand`
   - «تفاقمت الأزمة» → `The crisis worsened.`
4. **لا توجد ترجمة واحدة دائماً:** الاختيار يتحدد بالسياق.
   - «ينشئ»: `build` (مبنى) / `establish` (مؤسسة) / `set up` (شركة) / `create` (فكرة أو نظام).

## 2. الأزمنة وأدوات المعنى (Tense & Aspect Logic)

| الصيغة العربية | الشرط السياقي | المقابل الإنجليزي |
|---|---|---|
| قد + مضارع (احتمال) | دلالة احتمال | `may` |
| لقد + ماضٍ | بدون زمن محدد | Present Perfect: `have/has + Past Participle` |
| فعل ماضٍ + ظرف ماضٍ (أمس) | زمن ماضٍ محدد | Past Simple |
| كان قد + فعل | حدث قبل حدث ماضٍ | Past Perfect: `had + Past Participle` |
| كان + مضارع (استمرار) | حدث مستمر في الماضي | Past Continuous: `was/were + V-ing` |
| كان + مضارع (عادة) | عادة متكررة | Past Simple أو `used to` |
| «لم يعد» | نفي استمرار | `no longer` (رسمية، وتأتي بعد `to be`) أو `not ... anymore / any longer` (محادثة) |
| «إن» الشرطية | شرط | `If` |
| إن/أن (توكيد) | غالباً لا تُترجم حرفياً | يُفهم المعنى من السياق |

**قاعدة حرف اللام:**
- لام التعليل (الغاية) → `to / in order to / so as to`
- اللام بمعنى «من أجل» → `for`

## 3. بناء الجملة الإنجليزية (Syntax Rules)

1. **الأفعال الناقصة** (`can, could, may, might, must, should, will, would`) يتبعها المصدر بدون `to`.
2. **تركيب «من + الصفة + أن»:** `It + be + adjective + for + object + to + verb`.
   - «من الضروري أن نذاكر» → `It's necessary for us to study hard.`
3. **بعد حروف الجر** يأتي الفعل بصيغة `V-ing`: `good at studying`, `What about camping?`
4. **ترتيب الصفات** قد يخالف العربية — الهدف جملة طبيعية.
5. **ظروف المكان والزمان** تأتي في نهاية الجملة: `Subject + Verb + Object + Place + Time`.
   - «زار أحمد صديقه في الجزائر أمس» → `Ahmed visited his friend in Algeria yesterday.`
6. **`For + V-ing` مقابل `To + Infinitive`:**
   - `for + V-ing` = وظيفة الشيء (The pen is for writing).
   - `to + infinitive` = الهدف من الفعل (I went to the bank to get money).
7. **الاسم المفرد المعدود النكرة** يحتاج `a/an` — بحسب الصوت: `an hour`، `a university`.
8. **ليست كل to مصدرية:** بعد `look forward to, object to, contribute to, be used to` يأتي `V-ing`.

## 4. الأسماء والإضافة (Nouns & Possessive Rules)

1. **«كل»:** `every/each` + مفرد؛ `all` + جمع أو غير معدود.
2. **المضاف والمضاف إليه:** إما `of` أو الاسم المركب (الأكثر طبيعية): «تلوث البيئة» → `environmental pollution`، «حقوق الإنسان» → `human rights`.
3. **الملكية `'s`:** مفرد → `'s`؛ جمع ينتهي بـ s → `'` فقط؛ جمع لا ينتهي بـ s → `'s`. تُستخدم مع الأشخاص غالباً.
4. **تحويل الاسم إلى صفة** عندما تكون أكثر طبيعية: «يجب أن نتحلى بالصبر» → `We must be patient.`
5. **Gerund:** الاسم الدال على الفعل → `V-ing`: reading, writing, teaching.

## 5. الأفعال والتراكيب الشائعة (Verb Patterns)

- `Encourage + object + to + verb` — «تشجع الحكومة المستثمرين على إنشاء المصانع».
- **«يقوم بـ / يعمل على» لا تُترجم حرفياً** — يُترجم الفعل الأساسي مباشرة.
- `Prevent + object + from + V-ing`.
- **عبارة كاملة ↔ فعل واحد:** «يتمتع بـ» → `enjoy`؛ «يخاطر بـ» → `risk`؛ «يقلل من» → `reduce`.
- **حفظ الفعل مع حرف الجره:** `thank for`, `encourage to`, `forgive for`, `give up`.
- **التحقق من أسماء الأعلام** من مصادر موثوقة (Algeria/Algiers, Beijing, United Nations).

## 6. مفردات يكثر الخطأ فيها (Commonly Confused)

- `another` + مفرد («آخر/إضافي») / `other` + اسم / `others` تأتي وحدها.
- `teaching` = التعليم (بقِام المعلم) / `learning` = التعلم (بقِام المتعلم).
- `various` = متنوع (أنواع متعددة) / `different` = مختلف (غير متشابه).
- `big` = حجم ملموس / `great` = عظمة وأهمية وشدة (`great success` وليس `big success`).

## 7. قواعد الكتابة ونصائح للمترجم (Style & QA Workflow)

1. **كتابة الأعداد:** 1–9 بالحروف، 10+ بالأرقام؛ وإذا بدأت الجملة بالعدد فيُكتب بالحروف (مع مراعاة دليل الأسلوب APA/Chicago).
2. **مراجعة الترجمة قبل التسليم:** صحة المعنى، القواعد، الإملاء والترقيم، تناسق المصطلحات، عدم سقوط جمل.
3. **البحث الوثائقي** جزء أساسي: قواميس متخصصة، نصوص موازية، التحقق من المصطلحات والأعلام — «لا تخمن».
4. **الترجمة الآلية أداة مساعدة** لا مصدر نهائي — تُراجع وتُصحح.
5. **تطوير الثقافة العامة** والممارسة المستمرة والتعلم من تصحيحات الأساتذة.

## خلاصة قابلة للبرمجة (Implementable Pipeline)

```
Algorithm AR_EN_Translation(text):
  1. Read full text → global context, text type
  2. Identify: proper nouns, technical terms, idioms
  3. For each sentence:
     a. Resolve tense/aspect from context (see table §2)
     b. Restructure to S+V+C (see §1, §3)
     c. Apply noun/possessive rules (§4)
     d. Apply verb patterns & collocations (§5)
     e. Disambiguate confusables (§6)
  4. Post-process: numbers style, terminology consistency
  5. Review: meaning, grammar, spelling, omissions
```
